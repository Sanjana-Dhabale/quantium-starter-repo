## Quantium Software Engineering Virtual Experience

A Dash web application built to analyse Pink Morsel sales data for Soul Foods.

### Features
- Interactive line chart showing sales over time
- Region filter (North, East, South, West, All)
- Price increase marker on 15th January 2021
- Automated test suite with Pytest & Selenium
- CI bash script for automated testing

### How to Run
1. Activate virtual environment: `venv\Scripts\activate`
2. Run the app: `python app.py`
3. Open browser at: `http://127.0.0.1:8050`
